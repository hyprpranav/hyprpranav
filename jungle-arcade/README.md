# 🌿 AMAZON JUNGLE ARCADE // 3-in-1 Nature Sanctuary

> A lightweight, lush Amazon rainforest arcade suite featuring **Amazon Anaconda (Classic Jungle Snake)**, **Amazon River Rapids**, and **Canopy Wildlife Sprint**, engineered with pure **HTML5 Canvas**, **Vanilla JavaScript (ES6+)**, and a procedural **Web Audio API Nature Ambience Synthesizer** (flowing river water & nocturnal crickets).

---

## 🎮 3-in-1 Game Modes

### 1. 🐍 Amazon Anaconda (Primary Jungle Snake)
- Guide the emerald anaconda across the moonlit rainforest canopy.
- Hunt glowing golden fireflies / Amazonian berries.
- Each meal lengthens the snake; avoid collisions with ancient mossy stone borders and your own body!

### 2. 🛶 Amazon River Rapids (River Drift Runner)
- Pilot a river raft / canoe down rushing Amazonian rapids.
- Dodge river boulders, floating logs, and lurking caimans.
- Gather floating glowing water lilies for +150 bonus points.

### 3. 🐆 Canopy Wildlife Sprint (Agile Jaguar Sprint)
- Leap across giant moss-covered ancient branches high in the Amazon canopy.
- Time your jumps over bottomless ravines and duck under strangler fig vines.

---

## 🌊 Peaceful Nature Audio Engine

- **Procedural Amazon River Sound:** Dynamic bandpass-filtered continuous water flow white noise.
- **Nocturnal Rainforest Insects:** Periodic high-frequency gentle crickets and cicada chirps.
- **Zero External MP3 Assets:** Synthesizes sound directly in your browser using the `AudioContext` API. Never suffers from broken audio links or buffering delay.
- **Peaceful Ambient Toggle:** Click `🌊 AMBIENCE: ON` or press <kbd>M</kbd> anytime to toggle or mute.

## 🕹️ Controls

| Game | Desktop Input | Mobile Input |
| :--- | :--- | :--- |
| **Amazon Anaconda** | <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> or <kbd>Arrow Keys</kbd> | On-Screen Touch D-Pad |
| **River Rapids** | <kbd>A</kbd> / <kbd>D</kbd> or <kbd>◄</kbd> / <kbd>►</kbd> | Touch Left / Right Buttons |
| **Canopy Sprint** | <kbd>Space</kbd> / <kbd>W</kbd> / <kbd>▲</kbd> (Jump) | Touch Up Button |
| **Global Controls** | <kbd>P</kbd> (Pause), <kbd>M</kbd> (Sound Toggle) | HUD Control Buttons |
